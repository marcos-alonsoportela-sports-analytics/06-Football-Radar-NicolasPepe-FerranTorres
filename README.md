# 06-Football-Radar-NicolasPepe-FerranTorres
Comparative football performance analysis using radar charts and player metrics.
**Overview**

This project presents a comparative football performance analysis between Nicolas Pépé and Ferran Torres using radar visualisation.

The objective is to represent both player profiles through a common set of performance metrics and identify differences between their statistical profiles.

**Objectives**

Compare two attacking players using a common statistical framework.

Visualise differences between player profiles.

Use percentile-based metrics to contextualise performance.

Apply football-specific data visualisation techniques.

**Methodology**

The analysis follows these steps:

Data preparation.

Selection of relevant performance metrics.

Conversion of metrics into comparable values.

Construction of radar charts.

Visual comparison of both player profiles.

**Tools**

Python

Pandas

Matplotlib

soccerplots

Jupyter Notebook

**Output**

The final visualisation provides a direct comparison of Nicolas Pépé and Ferran Torres across the selected performance indicators.
